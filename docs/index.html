[03] ENGINEERING PRINCIPLES

Why Standalone SVGs Outperform Web Badges

Built from first principles to survive GitHub CDN caching mechanics and eliminate third-party API dependencies.

[01] CACHE RESILIENCE

GitHub Camo Proxy Immunity

GitHub proxies external images through camo.githubusercontent.com with aggressive cache headers. Dynamic API badges fail when upstream APIs rate-limit or timeout. Pixel Readme Kit compiles assets into your repository and appends deterministic SHA-256 hashes (?v=<hash>) during build.

[02] ADAPTIVE THEMING

Single-File CSS Media Queries

Each SVG includes embedded CSS @media (prefers-color-scheme: dark) rules. A single vector file shifts foreground contrast, grid visibility, and panel transparency when the user toggles between GitHub Dark and Light themes.

[03] DETERMINISTIC COMPILATION

Pure Python Stdlib (<40ms)

No Node.js, no Chromium binaries, no Cairo graphics bindings. The compiler runs on any standard Python 3.8+ installation with zero pip dependencies, making it instantaneous inside GitHub Actions CI runners.

[04] AI AGENT WORKFLOWS

Model Context Protocol (MCP)

Pixel Readme Kit ships with an integrated MCP server for Claude Code, Cursor, and Antigravity. AI coding assistants discover, scaffold, and recompile repository documentation autonomously without manual CLI steps.

Automated Scheduled Sync (GitHub Actions)

Keep star growth trajectories, issue counters, and contributor telemetry fresh on a daily cron without external webhooks:

name: Sync README Telemetry
on:
  schedule:
    - cron: '0 0 * * *' # Midnight UTC
  workflow_dispatch:

jobs:
  telemetry-sync:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
      - name: Recompile README with Live Stats
        run: |
          python -m generator.cli sync --fetch-github --bust-cache --clean-assets
      - uses: stefanzweifel/git-auto-commit-action@v5
        with:
          commit_message: "chore(readme): sync live github stars & telemetry [skip ci]"
