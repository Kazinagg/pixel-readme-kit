## 🏛️ 1. Архитектурный глоссарий дизайн-системы

Чтобы интерфейс собирался быстро и логично, в системе закрепляются следующие уровни компонентов:

```
[ MASTER HEADER ] ➔ Верхний баннер всего проекта / профиля
       │
       ▼
 [ GLOBAL DIVIDER ] ➔ Разделитель между главами (PCB, Laser, Wave)
       │
       ▼
 ┌─────────────── [ ОКНО (WINDOW / MODULE VIEWPORT) ] ───────────────┐
 │  [ FRAME TOP ] ➔ Верхняя крышка со скобами/скосами 45°           │
 │  [ TRANSITIONAL SHOULDER TOP ] ➔ Адаптер расширения контура      │
 │                                                                   │
 │  ┌─────────────── [ ТАБЛИЦА ИЗ 3 КОЛОНОК ] ────────────────────┐  │
 │  │ Левая шина (54px) │ Живой Markdown контент │ Правая (54px)  │  │
 │  │ (Gutter / Rail)   │   [ SUB-BLOCK SPLITTER ] (Внутри окна)  │  │
 │  │                   │ Живой Markdown контент │                │  │
 │  └─────────────────────────────────────────────────────────────┘  │
 │                                                                   │
 │  [ TRANSITIONAL SHOULDER BOTTOM ] ➔ Адаптер сужения контура      │
 │  [ FRAME BOTTOM ] ➔ Замыкающий поддон окна                       │
 └───────────────────────────────────────────────────────────────────┘
       │
       ▼
 [ GLOBAL DIVIDER ] ➔ Разделитель между главами
       │
       ▼
[ MASTER FOOTER / BOTTOM ] ➔ Завершающая нижняя пластина всего профиля
```

### Ключевые сущности:

1. **Главный Хедер (Master Header)**:
   - Флагманский титульный блок репозитория. Содержит 3D-шрифт, статусную панель, кнопки управления `[ _ ] [ □ ] [ × ]`, живой радар 360°, бегущую строку сканирования, эквалайзер и навигационные чипы.
2. **Главный Боттом / Футер (Master Bottom / Footer)**:
   - Завершающая монументальная пластина всего профиля/репозитория для каждой темы. Содержит системный статус (`SESSION TERMINATED // 0xDEADBEEF`), копирайт, ссылки на лицензию и кликабельную кнопку быстрого возврата наверх `[ ▲ RETURN TO TOP ]`.
3. **Окно (Window / Module Viewport)**:
   - Логический блок 2-го уровня, оформляющий смысловой раздел (`Overview`, `Installation`, `Architecture` и т.д.). Ограничивается сверху локальным `frame-top-*`, снизу `frame-bottom-*`.
   - **Строгое правило структуры окна**: разметка оформляется через 3-колоночную таблицу:
     - *Колонка 1 (Левая)*: фиксированная ширина (строго `width="54"` для дизеринг-шин или `width="40"` для лестничных рельсов).
     - *Колонка 2 (Центральная)*: 100% живой Markdown-текст, формулы KaTeX, списки, таблицы.
     - *Колонка 3 (Правая)*: симметричная фиксированная ширина (`width="54"` или `width="40"`).
4. **Разделения (Глобальные vs Внутренние)**:
   - *Глобальные разделители (Global Dividers)*: массивные самостоятельные линии между главами (`divider-pcb-cyan.svg`, `divider-laser-amber.svg`).
   - *Внутренние сплиттеры (Sub-Block Splitters)*: разделители подмодулей прямо внутри окна (`splitter-terminal-*.svg`, `splitter-tactical-*.svg`, `splitter-decay-*.svg`).

### 🧬 Иерархия дизайн-системы: Стили (Visual Paradigms) vs Темы (Themes & Palettes)

В системе строго разделяются два ортогональных уровня:

```
┌────────────────────────────────────────────────────────────────────────┐
│  УРОВЕНЬ 1: СТИЛЬ (STYLE / VISUAL PARADIGM)                             │
│  Геометрия контуров, алгоритм рендеринга текста, форма углов, декор    │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
       ┌────────────────────────────┼────────────────────────────┐
       ▼                            ▼                            ▼
  [ СТИЛЬ 1: PIXEL ]      [ СТИЛЬ 2: MODERN ]          [ СТИЛЬ 3: CORPORATE ]
  Retro-Tech / Скосы 45°  Clean Vector / Скругления    Academic / Строгие сетки
  3D пиксельный шрифт     Гладкие векторные пути       LaTeX & Stripe эстетика
  (РЕАЛИЗОВАН / STABLE)   (В РАЗРАБОТКЕ / ROADMAP)     (В РАЗРАБОТКЕ / ROADMAP)
       │                            │                            │
  ┌────┴────────────┐          ┌────┴────────────┐          ┌────┴────────────┐
  ▼ ТЕМЫ ПИКСЕЛЯ:   │          ▼ ТЕМЫ MODERN:    │          ▼ ТЕМЫ CORPORATE: │
  • cyberpunk       │          • slate-dark      │          • academic-paper  │
  • tactical        │          • nordic-frost    │          • enterprise-navy │
  • tokyo           │          • linear-violet   │          • swiss-mono      │
  • matrix / amber  │          • emerald-clean   │          • executive-slate │
  └─────────────────┘          └─────────────────┘          └─────────────────┘
```

1. **Стиль (Style / Visual Paradigm)**:
   - Отвечает за **форму, геометрию и физику рендеринга**.
   - Регулирует: используются ли скосы $45^\circ$, пиксельная сетка или скругления `rx/ry`; генерируется ли пиксельный 3D-шрифт (`render_3d_text`) или чистый векторный текст; присутствуют ли дизеринг-шины и сканирующие радары.
2. **Тема (Theme / Palette)**:
   - Отвечает за **колористику и настроение** внутри выбранного стиля.
   - Задает цвета фона, панелей, основного контура (`primary`), акцента (`accent`), третьего маркера (`tertiary`), статусов и текста в режимах Dark и Light.

- [X] **5. Проработка вариантов оформления вертикальных границ и устранение двойных рамок**

  - **Вариант 2А**: Одноячеечный бокс с внешними крышками `frame-top-*` и `frame-bottom-*` (зубцы точно позиционируются над 1px серыми гранями ячейки).
  - **Проблема «границы в границах» (Вариант 2Б)**: при размещении стандартного прямоугольного фрейма внутрь ячейки `<td>` возникало дублирование рамок (серая рамка таблицы + внутренняя рамка фрейма с отступом 13px).

  - **Цитаты `<blockquote>`**: протестированы как альтернатива без таблиц с вертикальной шиной `border-left`.
